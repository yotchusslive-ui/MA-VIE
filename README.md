IMPORTANT — GOOGLE CALENDAR
Une vraie lecture de l'agenda Google ne peut pas être faite simplement depuis un fichier HTML sans autorisation OAuth Google. Il faut créer/configurer un Client ID Google et autoriser Calendar API. Le bouton de l'application est volontairement honnête : il n'affiche pas de faux rendez-vous.
