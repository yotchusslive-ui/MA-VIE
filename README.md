# MA VIE — FINAL
Version cockpit mobile sombre et moderne.

Fonctions :
- Tableau de bord quotidien
- Priorité « Prendre mes 3 cachets » en première position
- Objectif poids 118 → 108 kg
- Sport / marche / guitare / culture / remise en question
- Travaux : 3 états uniquement Préparation → En cours → Terminé
- Un travail terminé passe automatiquement dans l’historique
- Bouton Ajouter un travail
- Onglet Rappels préparé pour Google Calendar
- Données locales dans le navigateur

Déploiement GitHub Pages :
1. Décompresser.
2. Mettre index.html à la racine du dépôt.
3. Commit.
4. Settings → Pages → Deploy from branch → main / root.
